Quiz Game 🎮
A simple and interactive Quiz Game built using Python. This project allows users to answer multiple-choice questions, calculates the score, and displays the final result at the end of the quiz.

Features ✨
Multiple-choice quiz questions

Score calculation

User-friendly interface

Instant result display

Easy to customize questions

Technologies Used 🛠️
Python

Project Structure 📂
quiz-game/
│── quiz_game.py
│── questions.py
│── README.md
How to Run ▶️
Install Python on your system.

Clone this repository:

git clone <your-github-repo-link>
Open the project folder:

cd quiz-game
Run the program:

python quiz_game.py
